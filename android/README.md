# Phone Remote — Android-оболочка

Приложение открывает веб-пульт Phone Remote (add-on для Kodi/CoreELEC) и принимает «Поделиться» из файлового менеджера:
файл НЕ копируется на приставку — телефон отдаёт его по HTTP (с перемоткой), Kodi играет прямо с телефона.

## Сборка (GitHub Actions)
1. Скопируйте папки `android/` и `.github/` в корень репозитория.
2. GitHub → Actions → «Build Android APK» → Run workflow (или просто сделайте commit).
3. Когда сборка зелёная — откройте её и скачайте артефакт `PhoneRemote-apk` (внутри PhoneRemote.apk).
4. Установите APK на телефон (разрешите установку из неизвестных источников).

## Использование
- При первом запуске введите адрес пульта, например `http://192.168.50.196:8090`.
  Сменить: долгое нажатие на значок приложения → «Сменить адрес».
- Файловый менеджер → «Поделиться» → Phone Remote: файл сразу играет на ТВ.
  Пока идёт просмотр, приложение должно оставаться запущенным (в шторке висит уведомление, «Остановить» закрывает раздачу).
- Ссылки (YouTube, magnet, прямые) из «Поделиться» тоже запускаются на ТВ.
- Телефон и приставка — в одной Wi-Fi сети.
